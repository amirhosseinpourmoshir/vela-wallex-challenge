# وِلا / Vela

پنل فارسی معاملات و آماده‌سازی دانش بازار؛ Node.js، React، Tailwind و SQLite در یک برنامه، بدون Docker یا میکروسرویس.

## اجرا

Node.js 24.18 یا جدیدتر از شاخهٔ 24 لازم است. SQLite داخلی Node استفاده می‌شود.

```powershell
Copy-Item .env.example .env
npm ci
npm run env:check
npm run markets:sync
npm run dev
```

آدرس: http://localhost:3000 — سرور فقط روی 127.0.0.1 است.

کلیدها را در فایل محلی .env قرار دهید؛ قالب بدون کلید در .env.example است. Node در شروع سرور فایل را می‌خواند و محیط سیستم اولویت دارد. بعد از تغییر تنظیمات سرور را مجدداً اجرا کنید. کلیدها در مرورگر یا متغیرهای VITE_* قرار نمی‌گیرند.

## ظاهر و تجربهٔ کاربری

رابط فارسی و راست‌به‌چپ با دو تم تیره و روشن ارائه می‌شود. دکمهٔ خورشید و ماه در نوار بالایی، تم را تغییر می‌دهد و انتخاب در مرورگر حفظ می‌شود. نشان وال اختصاصی و فونت محلی پیدا در هر دو حالت استفاده می‌شوند.

## امکانات فعلی

- ایجنت: تصمیم واقعی مدل، دیده‌بان کم‌مصرف، تحلیل چهار تایم‌فریم، دانشنامهٔ ۷۲ اصل، ریسک ده‌سطحی و ارزیابی تناسب هدف، بک‌تست یک دقیقه تا ۳۰ روز با سرمایهٔ مستقل پنج‌میلیونی و سرعت واقعی و ذخیرهٔ سمت سرور. لاگ تصمیم و معامله، نمودار سرمایه، توقف/ادامه و حذف نتایج اجرا در پنل وجود دارند.
- معاملهٔ واقعی در این نسخه فعال و پیاده‌سازی نشده است؛ تب واقعی وضعیت دسترسی حساب را نشان می‌دهد. موجودی واقعی کیف پول کلید متصل نمایش داده می‌شود؛ انتساب آن به طرح چالش به علت پاسخ۴۰۱ تأیید نشده و جداگانه مشخص است.

- نمای کلی: داشبورد مستقل با خلاصهٔ بازارهای صعودی و نزولی، موجودی مخزن دانش، فعالیت‌های اخیر و وضعیت تنظیمات سرویس‌ها؛ صفحهٔ بازارها مخصوص فهرست کامل قیمت‌ها و جست‌وجو است.

- بازارها: فقط تقاطع بازارهای تعهدی فعال والکس، پایهٔ TMN و محدودیت‌های طرح چالش؛ آخرین کشف ۱۷ بازار داشت. کارت‌های قیمت از WebSocket V2 و پشتیبان REST پنج‌ثانیه‌ای به‌روز می‌شوند. قیمت قدیمی با نشان هشدار مشخص می‌شود.
- آماده‌سازی دانش: انتخاب هر ارز، نوع پژوهشی، یادداشت الگوریتم، دریافت ۷ تا ۳۶۵ روز تاریخچهٔ موجود، گزارش پوشش، متن روزانه و embedding واقعی از BoxAPI با text-embedding-3-small.
- تست سرویس‌ها: بررسی خواندنی کلید والکس و پاسخ GPT-6 Luna؛ بدون ثبت سفارش. تست مدل و embedding می‌توانند هزینهٔ سرویس داشته باشند.
- دادهٔ خام، اسناد، بردارها، تنظیمات ارزها و وضعیت کارها در SQLite محلی نگه داشته می‌شوند.
- لوگوی وال با imagegen ساخته شده و فونت پیدا از فایل‌های محلی بارگذاری می‌شود؛ سرویس فونت خارجی لازم نیست.

## آنچه هنوز ساخته نشده

موتور اجرای سفارش واقعی، تطبیق سفارش‌ها و کنترل لیکوییدیشن واقعی هنوز ساخته نشده‌اند. ایجنت تحلیلی با RAG محدود به زمان، بک‌تست دقیقه‌ای و کنترل ریسک شبیه‌سازی اضافه شده‌اند. embedding آموزش وزن مدل یا پیش‌بینی تضمینی نیست. انتخاب «مشارکت ارز» اکنون اجازهٔ انتخاب آن در بک‌تست را می‌دهد. سیاست فعلی فقط تعهدی تومانی است؛ نوع معمولی صرفاً برای پژوهش ذخیره می‌شود و فعال‌سازی مشارکت آن توسط سرور رد می‌شود.

قیمت کارت بازارها، دادهٔ تاریخی و بردارها واقعی‌اند. اعداد سرمایه، نمودار و معاملات ساختگی از رابط حذف شده‌اند؛ صفحهٔ معاملات تا راه‌اندازی موتور، وضعیت خالی را نشان می‌دهد.

API حساب اعتباری چالش و سرویس تعهدی متفاوت‌اند. دسترسی به طرح فعال حساب پاسخ 401 داده؛ تطبیق طرح بر اساس عنوان دقیق و یکتا انجام شده است. فهرست عمومی تعهدی و موفقیت تست کلید، مجوز ثبت موقعیت تعهدی با سرمایهٔ چالش را اثبات نمی‌کنند.

## داده و کیفیت

تاریخچه از API رسمی خود والکس با نماد دقیق تومانی و resolution=1 دریافت می‌شود. درخواست‌ها به پنجره‌های روزانه تقسیم می‌شوند تا کوتاه‌شدن پاسخ‌های بزرگ پنهان نماند. کندل باز، زمان نامعتبر، OHLC ناسازگار و حجم منفی رد می‌شوند؛ دادهٔ گمشده ساخته نمی‌شود. واکشی افزایشی است: timestampهای موجود قبل از شبکه کنار گذاشته می‌شوند و فقط دقیقه‌های جدید یا مفقود درخواست می‌شوند. پاسخ‌های بدون داده با مهلت بازبینی ذخیره می‌شوند تا هر کلیک درخواست تکراری ایجاد نکند. متن و بردار بدون تغییر نیز حفظ می‌شوند. پوشش واقعی گزارش می‌شود؛ موجود بودن ۳۶۵ روز برای همهٔ ارزها تضمین نشده است.

متن روزانه شامل منبع، واحد تومان، زمان دسترسی شواهد، پوشش و تجمیع ساعتی است. سقف/کف ثبت‌شده صرفاً تاریخی است. بردارها در SQLite با مدل و ابعاد ذخیره می‌شوند. هر عملیات embedding فقط موارد باقی‌مانده را تا سقف تنظیم‌شده پردازش می‌کند. کارهای قطع‌شده هنگام restart خودکار ادامه پیدا نمی‌کنند؛ دادهٔ ثبت‌شده حفظ می‌شود.

## فایل‌ها

- server.js: سرور واحد، SQLite، APIها و WebSocket محلی.
- services/live-markets.js: جریان عمومی قیمت و پشتیبان REST.
- services/market-catalog.js و scripts/sync-markets.js: کشف و محدودسازی بازارها.
- services/history.js و services/knowledge.js: تاریخچه، ممیزی، اسناد و embedding.
- src/MarketCards.tsx و src/KnowledgeLab.tsx: رابط بازار و مخزن دانش.
- data/vela.sqlite: دیتابیس محلی؛ در Git نیست.

## معماری و نگه‌داری

یک فرایند Node.js رابط وب، API و جریان WebSocket را ارائه می‌کند. دادهٔ بازار فقط از سرور واکشی می‌شود؛ کلیدهای والکس و ارائه‌دهندهٔ مدل به مرورگر ارسال نمی‌شوند. فایل `.env.example` فقط قالب تنظیمات است و باید روی هر دستگاه جداگانه تکمیل شود.

پایگاه داده در اولین اجرا ساخته می‌شود. فایل‌های `.env`، دیتابیس، وابستگی‌ها و خروجی build در مخزن نگه‌داری نمی‌شوند. برای انتقال دادهٔ شخصی از فایل SQLite به‌صورت جداگانه نسخهٔ پشتیبان تهیه کنید. مخزن شامل سورس، فایل قفل وابستگی‌ها، آزمون‌ها، دارایی‌های رابط و مستندات راه‌اندازی است.

دریافت تاریخچه افزایشی است و بازه‌های ذخیره‌شده دوباره دانلود نمی‌شوند. سند بدون تغییر و بردار وابستهٔ آن حفظ می‌شود؛ شکاف‌های واقعی پس از پایان مهلت کش دوباره بررسی می‌شوند. راهنمای جزئیات در `docs/knowledge-lab.md` قرار دارد.
