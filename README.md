# Vela / وِلا

پنل محلی چالش والکس — اسکلت اولیه، بدون ایجنت و بدون ارسال سفارش واقعی.

## اجرا

Node.js 24.18 یا جدیدتر (شاخهٔ 24 LTS) لازم است. SQLite داخلی Node استفاده می‌شود؛ دیتابیس جداگانه لازم نیست.

```powershell
npm install
npm run dev
```

آدرس: http://localhost:3000

## بررسی و اجرای production

```powershell
npm run check
npm run build
$env:NODE_ENV='production'
npm start
```

سرور فقط روی 127.0.0.1 گوش می‌دهد. انتشار عمومی نیازمند احراز هویت و پیکربندی جداگانه است. فایل .env.example صرفاً نمونه است؛ متغیرها را در محیط تنظیم کنید.

## ساختار

- `server.js`: Express، Vite middleware در توسعه، SQLite و WebSocket روی همان پورت.
- `src/main.tsx`: پنل فارسی React، نمودار، جست‌وجوی بازار، تب‌ها، خروجی JSON و کنترل پیش‌نمایش.
- `src/style.css`: Tailwind CSS 4 و طراحی اختصاصی واکنش‌گرا.
- `public/logo.svg`: نشان اختصاصی Vela؛ لوگوی رسمی والکس نیست.
- `public/chart-icon.svg`: تصویر برداری ایزومتریک نمودار با عمق سه‌بعدی.
- `data/vela.sqlite`: هنگام اجرا ساخته می‌شود و در Git قرار نمی‌گیرد.

## وضعیت واقعی امکانات

تمام قیمت‌ها، معاملات، دلایل و نمودارها ساختگی و صرفاً برای نمایش رابط‌اند. بازه‌ها دادهٔ نمایشی را تغییر می‌دهند؛ بازده حساب واقعی نیست. دکمهٔ شروع فقط وضعیت پیش‌نمایش را در SQLite ذخیره می‌کند. WebSocket فقط اتصال محلی و heartbeat دارد. تنها تنظیمات پیش‌نمایش در SQLite ذخیره می‌شود؛ مخزن دادهٔ بازار هنوز ساخته نشده است.

اتصال والکس، مدل LLM، مدیریت ریسک، اجرای سفارش و بک‌تست هنوز پیاده‌سازی نشده‌اند. تب‌های ایجنت و مدیریت ریسک این موضوع را نمایش می‌دهند. گزارش JSON نیز برچسب demo دارد.

فونت Peyda با وزن‌های محلی از public/fonts/peyda بارگذاری می‌شود؛ اتصال به سرویس فونت خارجی لازم نیست. فایل‌ها از پروژهٔ torob_challenge کپی شده‌اند. نشان اختصاصی روبان V در public/logo.svg و نسخهٔ بدون زمینه در public/brand-mark.svg قرار دارند.

## API محلی

- `GET /api/status`: وضعیت زیرساخت و پیش‌نمایش
- `POST /api/pause`: بدنهٔ JSON شامل `paused` از نوع boolean
- `/ws`: وضعیت اتصال و heartbeat؛ فاقد دادهٔ زندهٔ بازار

معماری یک برنامهٔ واحد است؛ بدون Docker یا میکروسرویس. هیچ API key در این نسخه لازم نیست.
