# تنظیمات محیط

مرجع بارگذاری: `config/env.js`. قالب قابل اشتراک: [../.env.example](../.env.example). متغیر محیط سیستم بر فایل اولویت دارد. تغییر تنظیمات سرور نیازمند restart است. هیچ‌گاه config کامل را چاپ نکنید.

## پیش‌نیاز هر مسیر

| مسیر | لازم | لازم نیست |
| --- | --- | --- |
| دیدن اسکلت رابط | Node و SQLite داخلی | کلید حساب، LLM |
| کشف بازار/حساب | کلید والکس و حساب/طرح قابل تطبیق | LLM، embedding |
| محلی بدون مدل | حساب، whitelist، تاریخچه، ارز فعال، قابلیت سفارش و مجوز جلسه | هرگونه کلید/مدل LLM، بردارسازی |
| پیشنهاد مدل | پیش‌نیاز بازار و تنظیمات Chat Completions | embedding برای صرف پیشنهاد الزامی نیست |
| بک‌تست مدل | تاریخچه و مشخصات مدل پشتیبانی‌شدهٔ بخش بک‌تست | ارسال سفارش صرافی |
| embedding | متن تاریخچه، تنظیمات سرویس مدل، `EMBEDDING_MODEL` | اجازهٔ معامله |

بخش بک‌تست فعلی، نشانی BoxAPI یعنی `https://ai.boxapi.ir/ai/v1` را صریح بررسی می‌کند؛ مسیر پیشنهاد زنده قرارداد Chat Completions سازگار دارد. سازگاری هر ارائه‌دهنده را جداگانه تست کنید. نام مدل باید دقیقاً شناسهٔ قابل‌دسترسی در همان سرویس باشد.

## هسته و مجوز

- `NODE_ENV`: development/production/test؛ `PORT` پیش‌فرض 3000؛ `SQLITE_PATH` پیش‌فرض `./data/vela.sqlite`.
- `LIVE_ORDER_REVIEW_ENABLED=false`: قابلیت سفارش خاموش؛ برای استفاده از سفارش آن را صریح فعال کنید. خود این کلید شروع جلسه یا مجوز نامحدود نیست.
- `TRADING_MODE=demo`، `AGENT_ENABLED=false` و `LIVE_TRADING_ENABLED=false` کلیدهای **قدیمی** هستند و باید همین مقدار بمانند. فعال‌کردن آن‌ها در config رد می‌شود. واژهٔ demo در این کلید، اثبات دمو/بی‌اثر بودن درخواست سفارش نیست؛ موتور جلسه مستقل است.
- `TRADING_MARKET_TYPE` در قالب spot است؛ سیاست فعلی در کد اسپات را تحمیل می‌کند. `TRADING_QUOTE_ASSET=TMN`.

## والکس

| متغیر | توضیح |
| --- | --- |
| `WALLEX_API_KEY` | کلید مخصوص حساب انتخابی؛ هدر `x-api-key` |
| `WALLEX_SUB_ACCOUNT_ID` | تطبیق حساب و هدر `Sub-Account-Client-id`، نه شناسهٔ سفارش |
| `WALLEX_PACKAGE_ID` | تطبیق طرح و محدودیت بازار |
| `WALLEX_API_BASE_URL` | فقط `https://api.wallex.ir` پذیرفته می‌شود |
| `WALLEX_API_KEY_EXPIRES_AT` | ISO با timezone؛ اطلاعات تنظیمی، جایگزین بررسی صرافی نیست |
| `WALLEX_HTTP_TIMEOUT_MS` | مهلت درخواست؛ پیش‌فرض 10000 |
| `WALLEX_WS_ENABLED` | جریان عمومی قیمت؛ خاموشی آن پشتیبان REST را خاموش نمی‌کند |
| `WALLEX_WS_URL` | فقط نشانی V2 رسمیِ قالب |
| `WALLEX_ORDER_REQUESTS_PER_10_SECONDS` | بودجهٔ محلی درخواست سفارش؛ جایگزین محدودیت واقعی سرویس نیست |

`markets:sync` شناسه‌ها، whitelist، نمادهای قیمت و نوع بازار را در فایل محلی به‌روز می‌کند. اعتبار کلید از `env:check` معلوم نمی‌شود. موفقیت خواندن نیز مجوز نوشتن را اثبات نمی‌کند.

## بازار و مدل

- `TRADING_ALLOWED_SYMBOLS` whitelist دقیق نماد API؛ خالی به معنی اجازهٔ همه نیست.
- `TRADING_BLOCKED_SYMBOLS` محدودیت اضافه؛ denylist برگزارکننده از فایل سیاست اضافه می‌شود.
- `MARKET_DATA_SYMBOLS` فهرست تنظیمی داده؛ دامنهٔ مجاز سفارش با فعال‌بودن ارز و محدودیت حساب دوباره محدود می‌شود.
- `LLM_API_BASE_URL` ریشهٔ API، نه مسیر `/chat/completions`؛ `LLM_API_KEY` و `LLM_MODEL` برای مسیر مدل.
- `LLM_MAX_CALLS_PER_DAY` و `AGENT_MAX_TOKENS_PER_DAY`: صفر سقف اختیاری برنامه را غیرفعال می‌کند؛ سهمیه/هزینهٔ سرویس باقی است. مسیر محلی این سهمیه را مصرف نمی‌کند.
- مهلت مؤثر پیشنهاد زنده ممکن است از `LLM_HTTP_TIMEOUT_MS` بزرگ‌تر باشد؛ کد این مسیر حداقل ۱۲۰ ثانیه مهلت مدل می‌گذارد، اما TTL سناریو مستقل است.
- `EMBEDDING_MODEL`: text-embedding-3-small یا large؛ batch و سقف اسناد در `EMBEDDING_BATCH_SIZE` و `EMBEDDING_MAX_DOCUMENTS_PER_JOB`.

## MCP

اختیاری و فقط خواندنی: `WALLEX_MCP_ENABLED=true` و `WALLEX_MCP_SERVER_URL=https://api.wallex.ir/mcp`. کلاینت از کلید والکس و scope حساب استفاده می‌کند؛ `WALLEX_MCP_AUTH_TOKEN` در آداپتور فعلی مصرف نمی‌شود. ابزار سفارش/برداشت/لغو از MCP مجاز نیست؛ سفارش از REST می‌رود.

## تنظیمات رزروشده و حدود واقعی ریسک

بخشی از متغیرهای قالب از اسکلت اولیه‌اند؛ parse شدن به معنی اعمال در موتور جلسه نیست. `RISK_*` سقف‌های عمومی اسکلت‌اند؛ اندازه، سهم هر ارز، TTL، لغزش و سقف زیان مؤثر اجرای زنده از **تنظیمات ثبت‌شدهٔ جلسه** و محاسبهٔ quote می‌آیند. `RISK_MAX_ORDER_TMN=0` را کلید تضمینی قطع موتور جلسه فرض نکنید.

همچنین همهٔ متغیرهای `MARKET_*`، `CHALLENGE_*`، نسخه/فاصلهٔ `AGENT_*` یا `LLM_MAX_OUTPUT_TOKENS/MAX_RETRIES` به تمام مسیرها سیم‌کشی نشده‌اند. timestampها ISO/UTC هستند؛ برنامه پایان زمانی چالش را صرف وجود `CHALLENGE_END_AT` به‌صورت تسویهٔ صرافی تضمین نمی‌کند. از انقضای مجوز جلسه و کنترل سفارش استفاده کنید.
