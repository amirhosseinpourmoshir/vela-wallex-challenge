# سیاست چالش

مبنا: توضیح تکمیلی کاربر در ۲۰۲۶-۱۰-۲۳؛ فقط اسپات و بدون اهرم. این فایل جایگزین قرارداد برگزارکننده نیست؛ تغییر قانون باید در کد و تست ثبت شود.

## انتخاب بازار

۱. بازار در اطلاعات تازهٔ والکس اسپات فعال باشد.
۲. دامنهٔ فعلی TMN است؛ تومان با ریال متفاوت است.
۳. بازار در `unavailableMarkets` طرح نباشد.
۴. ۳۴۵ جفت‌ارز در `config/challenge-markets.js` ممنوع‌اند؛ `/` برای نماد API حذف می‌شود. ممنوعیت یک جفت به جفت دیگر تعمیم داده نمی‌شود.
۵. `TRADING_BLOCKED_SYMBOLS` محدودیت اضافه است؛ بازار باید در whitelist و انتخاب فعال کاربر باشد.

تعداد باقی‌مانده زنده است. snapshot گذشته تضمین اجازهٔ ارسال آینده نیست؛ بررسی هنگام ساخت و ارسال تکرار می‌شود.

## معامله

- ورود: خرید اسپات از موجودی آزاد.
- فروش: فقط دارایی موجود؛ فروش خودکار به دارایی کسب‌شدهٔ همان جلسه محدود است.
- تعهدی، شورت بدون دارایی، وام، اهرم و برداشت در مسیر مجاز چالش نیستند.
- ریسک ۱۰، ضریب ۱۰ یا استفادهٔ اجباری از تمام سرمایه نیست.
- سازوکار Wash Trading یا معاملهٔ درون‌تیمی پیاده نشده است؛ API مجوز چنین رفتاری نیست.

## ارزیابی

گزارش باید هزینه، لغزش، عدم‌پرشدن و دادهٔ ناقص را نشان دهد. تست چرخهٔ اجرای اجباری از ارزیابی استراتژی جداست. سود و برد تضمین نمی‌شوند.

دمو بودن حساب از پاسخ عمومی بازار قابل استنتاج نیست. کد سفارش را به API حساب تنظیم‌شده می‌فرستد؛ عنوان چالش نباید ارسال را بی‌اثر فرض کند.
